# The projection model — policy is the map

```
policy items   the fixed terrain — coordinates are role × risk × provision
    agents     points (allocation) and paths (actions) embedded onto it
    binding    (agent, action) ──approved-under──▶ policy item
```

- Conduct is read off the policy, never the reverse.
- The interpreter reshapes the map (a holding re-reads a provision) → agents re-fold.
- A derived solver shapes an agent's *path*, not the terrain.
- A case-law reading is not an agent gate; it edits a provision, which re-compiles items.
- Policy and agents both project into the 5D graph — policy is its fixed frame.
